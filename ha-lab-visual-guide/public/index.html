01 / 수업의 흐름

하나의 수업이
이렇게 이어집니다.

수업 준비부터 다음 수업의 보충 설명까지,
네 단계로 살펴보세요.

  1. 01
    운영 담당자 / 교수

    수업을 준비해요

    운영 담당자가 교재와 수업 반을 연결합니다. 교수는 교재를 확인하고 학생에게 참여 코드를 안내합니다.

  2. 02
    학생

    참여하고 공부해요

    코드로 수업에 참여합니다. 교재의 해설과 자료를 보고, 퀴즈를 풀며 학습합니다.

  3. 03
    교수

    학습 현황을 살펴봐요

    누가 참여했는지, 퀴즈를 풀었는지, 어떤 문제를 많이 틀렸는지 확인합니다.

  4. 04
    교수

    다음 수업에 활용해요

    학생들이 어려워한 부분을 다시 설명하고, 공지로 다음 학습을 안내합니다.

학기가 끝나면 정해진 기간에 이전 기록을 확인하고, 새 학기는 새 반으로 시작해요.

03 / 핵심 기능과 확장 방향

수업에 필요한 기능부터,
차근차근.

교재 기반의 학습과 수업 운영을 중심으로,
사용 수요에 따라 기능을 확장합니다.

수업에 필요한 핵심 기능

수업 개설과 학생 참여, 교재 자료와 퀴즈 학습, 학생별 학습 현황과 많이 틀린 문제 확인을 연결합니다.

공지와 학생 참여 상태 관리, 학생 화면 미리보기, 학기별 기록 보관까지 준비합니다.

수업 운영을 돕는 확장 기능

수업 준비
교수가 직접 수업을 개설하고, 다음 학기에 수업 구성을 복사해 활용합니다.
학습과 질문
학습 일정과 퀴즈 운영을 설정하고, 질문과 답변 및 수업별 보충자료를 제공합니다.
공동 관리
공동 교수와 조교가 권한에 따라 수업을 함께 관리하고, 학습 결과를 내려받습니다.

수요 확인 후 검토

출결, 과제 제출, 공식 성적 관리 등은 실제 수업의 필요와 운영 부담을 확인해 개발 여부를 정합니다.
